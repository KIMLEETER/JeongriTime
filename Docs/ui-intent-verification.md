# 정리시간 UI 의도 및 검증

검증일: 2026-05-21
대상: macOS 개발 빌드, iOS Simulator 개발 빌드
기준 버전: 0.2.x 개발 빌드

## 검증 원칙

- 큰 탭은 `오늘`, `시간표`, `통계`, `설정` 네 개다.
- `시간표` 안에서는 `빈시간`이 기본이고, `주간`, `관리`는 보조 모드다.
- 빈 시간을 새 계획으로 채우는 기본값은 `이번만`이다.
- 시간표 자체를 바꾸지 않고 오늘만 달라진 상황은 `오늘만 조정`으로 처리한다.
- 캘린더에서 들어온 새 일정은 바로 시간표에 섞지 않고 `확인 필요`에서 사용자가 성격을 정한다.
- Google 로그인, Drive 동기화, 캘린더 권한, 알림 권한, 삭제, 연결 해제처럼 실제 계정/권한/데이터를 바꾸는 동작은 UI와 버튼 상태까지만 확인하고 최종 실행은 보류했다.

## 상태 표기

| 상태 | 뜻 |
| --- | --- |
| 통과 | 실제 클릭으로 화면 전환, 편집 시트, 상태 변화가 확인됨 |
| 부분 | 버튼과 UI는 확인했지만 외부 계정/권한/실제 데이터 때문에 최종 효과는 제한 검증됨 |
| 보류 | 삭제, 연결 해제, 실제 로그인/권한 승인처럼 사용자 데이터나 외부 상태를 바꾸므로 실행하지 않음 |
| 해당 없음 | 해당 플랫폼에는 기능이 없음 |
